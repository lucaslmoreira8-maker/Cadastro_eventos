# Calculo de Diaria - Atividade ETEC
Esse projeto está sendo feito em C#, onde estou praticando conceitos do para o desenvolvimento  em NEt.MAUI.

Nesse projeto você colocara a quantidade de adultos e crianças que irá levar, o Evento que você quer, os dias que você quer ocupar o espaço. Então ele dará a quantidade de crianças e adultos que você colocou, as datas selecionadas com a quantidade de dias que você vai ficar e o preço total do evento
